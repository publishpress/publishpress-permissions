# Advanced Custom Fields and PublishPress Permissions (Pro)

This feature requires the Pro version of the PublishPress Permissions plugin.

Advanced Custom Fields is a plugin that allows you to quickly and easily add fields to WordPress posts. With the Pro version of [PublishPress Permissions](https://publishpress.com/links/permissions), you can control who can view Field Groups created with Advanced Custom Fields.

[PublishPress Permissions](https://publishpress.com/links/permissions) can control viewing access to all the fields inside a Field Group. In the screenshot below, you can see a sample Field Group with three fields. This Field Group is called “My Fields”.

![Advanced Custom Fields and PublishPress Permissions: Field Group](https://docs-media.publishpress.com/publishpress-permissions/acf-fields-view-93f57d515e.webp)

To control view access, go to the “Permissions” link in the WordPress admin area. You can edit a user role, user group, or individual user.

- **Post Type**: Field Group
- **Operation**: View
- **Adjustment**: Choose Enable or Block
- **Select Field Groups**: Choose the Field Groups that you want to control access to.

![Advanced Custom Fields and PublishPress Permissions: View access for a Field Group](https://docs-media.publishpress.com/publishpress-permissions/permissions-group-acf-bcbfb7c6db.webp)
