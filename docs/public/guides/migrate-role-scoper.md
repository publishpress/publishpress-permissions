# How to Migrate from Role Scoper to PublishPress Permissions

Table of Contents

- [How to Migrate from Role Scoper](#0-toc-title)

The [Role Scoper](https://wordpress.org/plugins/role-scoper/) plugin is no longer supported.

We strongly recommend that you update from Role Scoper to [the PublishPress Permissions plugin](https://wordpress.org/plugins/press-permit-core/).

There is an automatic update script that will help you move from Role Scoper. All the features you saw in the old Role Scoper plugin are now available in the new [PublishPress Permissions](https://publishpress.com/links/permissions).

## How to Migrate from Role Scoper [#](#0-toc-title)

If you are using Role Scoper, you will see a banner that encourages you to start the migration process:

![Role Scoper](https://docs-media.publishpress.com/publishpress-permissions/role-scoper-import-a6d3e5c719.webp)

- Click the purple “Run the migration process” button.
- The migration script will analyze your site and show you what features can be migrated:

![](https://docs-media.publishpress.com/publishpress-permissions/migration-preview-100a1ab879.webp)

- Scroll down and you will see Step 2, which involves installing the [PublishPress Permissions](https://publishpress.com/links/permissions) plugin.
- Click either “Install PublishPress Permission” or “Buy [PublishPress Permissions Pro](https://publishpress.com/links/permissions)“.

![](https://docs-media.publishpress.com/publishpress-permissions/install-permissions-3e7fa3b81f.webp)

- When PublishPress Permissions is installed, you will see a message saying “Role Scoper installation detected. To migrate your groups, roles, restrictions and options to PublishPress Permissions, run the Import tool.”
- Click the “Import tool” link.

![](https://docs-media.publishpress.com/publishpress-permissions/run-import-tool-d57e6551ab.webp)

- You will now be on the import screen. Click “Do Import”.

![](https://docs-media.publishpress.com/publishpress-permissions/do-import-70b76b1777.webp)

- You will now see the results of your migration. In the image below, the result is “General Roles imported: 2”.

![](https://docs-media.publishpress.com/publishpress-permissions/import-finished-1870295bc8.webp)

Now you can test the results of your import.

- Go to the “Plugins” link in your WordPress admin menu.
- Disable the “Role Scoper” plugin.
- Test your user accounts and permissions. Make sure that the information has migrated correctly.
- Is everything working as you want? You can go to the “Plugins” link in your WordPress admin menu and delete the “Role Scoper” plugin.

If you have any questions about moving from Role Scoper, [click here to get in touch with us](https://publishpress.com/contact/).
