# bbPress and PublishPress Permissions (Pro)

Table of Contents

- [Permissions for bbPress Forums](#h-permissions-for-bbpress-forums)
- [Adding bbPress Roles to Users](#h-adding-bbpress-roles-to-users)

This feature requires the Pro version of the PublishPress Permissions plugin.

bbPress is the most popular forum software for WordPress. With the Pro version of [PublishPress Permissions](https://publishpress.com/links/permissions), you can manage access and to important bbPress features.

One key features of [PublishPress Permissions Pro](https://publishpress.com/links/permissions) is that you can control permissions for specific bbPress forums.

## Permissions for bbPress Forums [#](#h-permissions-for-bbpress-forums)

Here’s the way to start adding permissions for specific bbPress forums:

- Go to “Permissions” then “Settings” in the WordPress admin menu.
- Enable the box for “Forums”.

![bbPress Forums checkbox](https://docs-media.publishpress.com/publishpress-permissions/bbpress-forums-a3444675e8.webp)

You will now see several boxes under each forum. The boxes control different permissions for this forum:

- **View this Forum**: who can view posts in this forum.
- **Create Topics in this Forum**: who can create posts in this forum.
- **Submit Replies in this Forum**: who can reply to posts in this forum.
- **Moderate / Edit this Forum**: who can edit / moderate posts in this forum.
- **Select this Forum as Parent**: who can move this forum to a different place in the forum hierarchy.
- **Assign Terms to this Forum**: who can add taxonomy terms to posts in this forum.

## Adding bbPress Roles to Users [#](#h-adding-bbpress-roles-to-users)

It is also possible to give bbPress roles to specific users or groups. This means you could choose to make a single user into a bbPress Moderator without promoting everyone else who is in the same role as that users.

- Go to “Permissions” in the WordPress admin menu.
- Click the “Users” tab.
- Click to edit the user you want to modify.
- Choose “Forum” from the “Post Type” dropdown.
- Choose “Participant” or “Moderator”.
- Click “Add Role” then “Save Roles”.

This specific user will now have this supplemental role in addition to their normal WordPress role.
