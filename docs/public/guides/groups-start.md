# Getting Started with Permission Groups

Table of Contents

- [How to Create New Groups](#h-how-to-create-new-groups)
- [What Can You Do With Groups?](#h-what-can-you-do-with-groups)

Permission Groups are one of the most flexible features in [PublishPress Permissions](https://publishpress.com/links/permissions).

You can use groups to set permissions for WordPress users. One advantage of this is that a user can be in multiple groups, which isn’t normally possible with the default user roles.

When you first install [PublishPress Permissions](https://publishpress.com/links/permissions), some roles will already be set up for you. These are four of the default WordPress user roles:

- Author
- Contributor
- Editor
- Subscriber

![Permissions screen in WordPress](https://docs-media.publishpress.com/publishpress-permissions/permissions-screen-d067f2c4b9.webp)

## How to Create New Groups [#](#h-how-to-create-new-groups)

You can also create new groups by clicking “Add New”.

![](https://docs-media.publishpress.com/publishpress-permissions/new-permissions-group-8be3316e15.webp)

You can search for and add the users you want to include in this group.

## What Can You Do With Groups? [#](#h-what-can-you-do-with-groups)

There many powerful features you can add to groups. Here are some of the most common ways that people use PublishPress Permissions groups to manage their users:

- [Extra Roles](https://publishpress.com/knowledge-base/supplemental-roles/)
