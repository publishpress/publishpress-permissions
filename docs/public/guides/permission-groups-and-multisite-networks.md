# Permission Groups and Multisite Networks (Pro)

The Pro version of [PublishPress Permissions](https://publishpress.com/links/permissions) does allow to you to create groups that work across all the sites in the multisite network.

You can enable this feature by going to Permissions > Settings > Network in the main site on your network.

![Multisite and Permissions](https://docs-media.publishpress.com/publishpress-permissions/permissions-pro-multisite-a7b35285e2.webp)

After this is enabled, your groups, and their user membership list, will become available on all sites in the network.

It is important to understand that these groups do **not** automatically grant permissions network-wide. [Extra roles](https://publishpress.com/knowledge-base/supplemental-roles/) and [Specific Permissions](https://publishpress.com/knowledge-base/exceptions/) are still set per-site.
