# Blocked vs Enabled

In [PublishPress Permissions](https://publishpress.com/links/permissions), the plugin allows you to choose “Blocked” or “Enabled”. These choices can apply to user roles, groups, and login states such as “Logged In” and “Logged Out”.

“Blocked” will always take precedence. If a “Blocked” is applied to a user through any role, group, or state, then it doesn’t matter how many times “Enabled” is applied.
