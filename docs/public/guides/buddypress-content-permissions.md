# BuddyPress and PublishPress Permissions (Pro)

This feature requires the Pro version of the PublishPress Permissions plugin.

With the Pro version of the [PublishPress Permissions](https://publishpress.com/links/permissions) plugin, you can give users access to create WordPress content, based on their BuddyPress group membership.

- Make sure you have [PublishPress Permissions Pro](https://publishpress.com/links/permissions) plugin installed.
- Ensure you have the “User Groups” feature enabled in BuddyPress.

![Buddypress Groups Departments](https://docs-media.publishpress.com/publishpress-permissions/buddypress-groups-departments-4f9f37becf.webp)

*Buddypress Groups Departments*

- Click the “Permissions” link under a group

![Buddypress Groups Permissions](https://docs-media.publishpress.com/publishpress-permissions/buddypress-groups-permissions-2449473af0.webp)

*Buddypress Groups Permissions*

- On the next screen, you will see the group, together with all the members.

- You can now choose specific permissions for all the users in this BuddyPress group.
