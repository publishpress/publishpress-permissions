## Installing and Configuring PublishPress Permissions [#](#h-installing-and-configuring-publishpress-permissions)

The free version is available [on WordPress.org](https://wordpress.org/plugins/press-permit-core/). [PublishPress Permissions Pro](https://publishpress.com/links/permissions) has many more features and is available to PublishPress members.

- Install either [PublishPress Permissions](https://publishpress.com/links/permissions) Free or [PublishPress Permissions Pro](https://publishpress.com/links/permissions).
- Go to the “Permissions” link in the WordPress admin menu.
- Click “Settings”.
- Click the “Core” tab.
- Under “Filtered Post Types”, you can choose the post types you want to use with PublishPress Permissions:

![Permissions settings](https://docs-media.publishpress.com/publishpress-permissions/permissions-settings-a8e08a6b32.webp)

## Permissions inside Posts or Terms [#](#h-option-1-using-publishpress-permissions-for-content)

This feature allows you to control who can see and read the content. You can find these settings inside Posts, Pages, Categories, and Tags.

- In the image above, we selected “Posts”.
- Go to the “Posts” screen and edit a post.
- Scroll down and you can see the PublishPress Permissions metaboxes. Here you can control who is able to access this post. [Click here for a guide to using this feature](https://publishpress.com/knowledge-base/multiple-users-edit-wordpress-post/).

![Permissions Metabox](https://docs-media.publishpress.com/publishpress-permissions/permissions-metabox-b309ee28fe.webp)

## The Permissions Screen [#](#h-option-2-publishpress-permissions-for-users)

This feature allows you to control the permissions for multiple posts at once.

- Go to “Permissions” in the WordPress admin menu.
- Choose a role that you want to edit. In this example, we’ll choose “Author”.

![Permissions screen in WordPress](https://docs-media.publishpress.com/publishpress-permissions/permissions-screen-d067f2c4b9.webp)

Inside this area, you can create custom permissions for users.

- Click the “Add Specific Permissions” tab.
- Choose a post type:

![Edit Permissions group](https://docs-media.publishpress.com/publishpress-permissions/permission-specific-15a69a89b6.webp)

Now you can give very specific permissions to this user role. For example, you can allow users in this role to read (or not) content with a particular category or tag. When you’re finished, click “Add Selected” and then “Save Permissions”.

![Edit Permission Group](https://docs-media.publishpress.com/publishpress-permissions/edit-permission-group-3872b21f71.webp)
