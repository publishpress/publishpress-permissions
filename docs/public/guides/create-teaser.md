# How to Create Your First Teaser

The “Teaser” feature in [PublishPress Permissions Pro](https://publishpress.com/links/permissions) is useful if you want to give users details about content they are not allowed to see.

This guide will show you how to set up a Teaser. You can use it encourage users to join your site.

- Install the [PublishPress Permissions Pro](https://publishpress.com/links/permissions) plugin.
- Go to “Posts” and edit a post.
- Scroll down to the “Permissions: Read this Post” box. In the image below, my post is called “This Post is for Members Only” and the box is under the post.

![This post is for members only](https://docs-media.publishpress.com/publishpress-permissions/teaser-setting-401ba756a1.webp)

- Set “Not Logged In” to “Blocked” as in the image below. This means that visitors who are not logged-in will NOT be able to see this content.

![Not Logged in Users are blocked](https://docs-media.publishpress.com/publishpress-permissions/not-logged-in-blocked-b2429a5fc9.webp)

*Read Post Blocked*

- Go to Permissions > Teaser.
- Choose “Posts” under “Select Post Type to Configure”.
- Choose “Teaser Text” for the “Teaser Text” option.

![Teaser options](https://docs-media.publishpress.com/publishpress-permissions/teaser-text-options-dfc26caa9a.webp)

*Hidden Content Teaser*

- Scroll down and you will be able to choose the text that will show to users who access restricted content.

![Content to add to posts](https://docs-media.publishpress.com/publishpress-permissions/replace-post-content-171fd2994d.webp)

- Save your Teaser settings.
- As a logged-out visitor, go to the post that you restricted access to at the beginning of this guide. The best way to do this is by opening a private window in your browser, or opening a new browser. This image below shows what you’ll see. The visitor will see the text before the title and also this message “Sorry, you don’t have access to this content.”

![Members only content](https://docs-media.publishpress.com/publishpress-permissions/teaser-feature-demo-a3cdbd731f.webp)
