# Membership: Date Limits for Group Members (Pro)

This feature requires the Pro version of the PublishPress Permissions plugin.

This feature of [PublishPress Permissions](https://publishpress.com/links/permissions). allows you to set date limit on [Permission Group membership](https://publishpress.com/knowledge-base/groups/).

This only applies to custom user groups.

By default, [PublishPress Permissions](https://publishpress.com/links/permissions) also creates groups for the WordPress user roles (Subscriber, Contributor, Author, Editor) but membership in those groups can not be time limited.

- Go to Permissions > Settings > Features.
- Check the box for “Membership”.
- Click “Save Changes”.

Now you can use this feature:

- Go to Permissions > Groups.
- Click “Add New”.
- In the “Group Members” area you can search for members to add to your site.
- In the bottom of the “Group Members” area, you can choose a “From” and “To” date for the group membership.
